# 功能开发清单

> 本文件只跟踪开发状态和验收进度；功能边界以 [系统需求与架构](../系统需求与架构.md) 为准。

## 状态说明

| 状态 | 含义 |
|---|---|
| 未开始 | 尚未实现 |
| 进行中 | 已有部分代码，主流程未完成 |
| 已可用 | 主流程可运行并通过验收 |
| 暂停 | 本期不实现，已记录原因 |

## 核心功能

| 编号 | 功能 | 模块 | 状态 | 验收要点 |
|---|---|---|---|---|
| FR-01 | 登录与会话 | M01 | 未开始 | 未登录不可访问受保护功能 |
| FR-02 | 文档上传与管理 | M02 | 未开始 | PDF、DOCX、TXT 可上传、查看、重命名和删除 |
| FR-03 | 分类与标签 | M03 | 未开始 | 文档可分类并关联多个标签 |
| FR-04 | 解析与入库任务 | M04 | 未开始 | 提取文本、页码、字符位置和分块；失败可重试 |
| FR-05 | 关键词与全文检索 | M05 | 未开始 | PostgreSQL 全文检索返回命中文档和片段 |
| FR-06 | 语义检索 | M05 | 未开始 | BGE + pgvector 返回语义相关片段 |
| FR-07 | 文档摘要 | M06 | 未开始 | 生成摘要、要点和关键词并记录模型信息 |
| FR-08 | 文档问答 | M07 | 未开始 | 回答带引用，证据不足时拒答 |
| FR-09 | 大模型异常处理 | M08 | 未开始 | 超时、限流、鉴权和服务错误可恢复 |
| FR-10 | AI 结果准确性评价 | M08 | 未开始 | 固定评测集和评分标准可复现 |
| FR-11 | 系统测试与交付 | M08 | 未开始 | 核心流程、异常流程和基本性能测试完成 |

## 本期不做

| 功能 | 原因 |
|---|---|
| 团队协作和复杂权限 | 个人单用户系统，不影响课题目标 |
| 模型训练与微调 | 以现有模型和 API 完成应用目标 |
| 扫描件 OCR | 增加识别链路，留作扩展 |
| 旧版 `.doc` 解析 | 要求用户另存为 `.docx` |
