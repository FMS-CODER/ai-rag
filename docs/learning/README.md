## 记录规则

- 一个问题一篇，标题写“功能/模块：问题一句话”。
- 必须写清：现象、原因、解决、验证。
- 暂时没解决或只是绕过，写“遗留”，注明触发条件和影响。
- 只放关键代码片段或文件链接，不贴整段代码。
- 解决后回到 [功能清单](../requirements/功能清单.md) 更新状态。
